# IPL Ticket Booking Website

A simple IPL Ticket Booking Website developed as part of my Web Development activities using HTML, CSS and JavaScript.

## Activities Completed

### Activity 1 – HTML Structure

**Features**
- Navigation bar with section links
- Hero section with booking links
- About IPL section
- Popular IPL teams and venues
- Match schedule table with ticket prices
- Team filter dropdown
- Ticket booking form
- Booking summary section
- My Bookings section
- Ticket booking guidelines

### Activity 2 – CSS Styling

- Styled navigation bar and website sections
- Designed a dark blue and gold theme
- Styled tables, forms, buttons and booking cards
- Improved the overall website appearance

### Activity 5 – JavaScript Basics and User Interaction

- Created a reusable `showToast()` function
- Implemented DOM manipulation
- Added click event handling
- Implemented smooth scrolling from Match Schedule to the booking form
- Added toast notifications when the Book button is clicked

## Technologies Used
